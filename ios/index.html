Подключение за 5 минут

  1. Открой «Быстрые команды» → «+» → новая команда Alerta (или нажми «Добавить готовую команду», если кнопка есть ниже).
  2. Действие «Получить содержимое URL». URL: адрес из блока выше. Метод POST, тело запроса JSON, два поля: token (текст, твой токен) и text (переменная «Входные данные команд»).
  3. Вкладка «Автоматизация» → «+» → Уведомление → приложение Kaspi.kz → «Далее» → «Выполнить быструю команду» → Alerta.
  4. Включи «Выполнять сразу», выключи «Уведомлять при запуске».
  5. Когда iOS спросит разрешение отправить данные на mutxeactljgbuygzfhim.supabase.co, нажми «Всегда разрешать».
  6. Настройки → Уведомления → Kaspi.kz: разреши уведомления и показ на заблокированном экране. Без этого автоматизация не срабатывает.
  7. Ссылку оверлея добавь в TikTok Live Studio источником «Ссылка», включи звук.
