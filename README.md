# Alerta — сайт

Статичный сайт для GitHub Pages: `nest-model.github.io/alerta`.

- `index.html` — главная: что такое Alerta, ролик, установка, вопросы, скачивание.
- `d/index.html` — страница доната стримера: `nest-model.github.io/alerta/d/?ник`
- `404.html` — короткие ссылки `nest-model.github.io/alerta/ник` ведут на страницу доната.
- `assets/config.js` — версии и ссылки на скачивание. При новой версии меняй здесь.
- `download/` — сами файлы: `Alerta.apk` и `Alerta-Setup.exe`.

Новая версия: замени файл в `download/`, поправь версию в `assets/config.js`, запушь.
В админке Alerta (вкладка «Обновления») впиши ссылку `https://nest-model.github.io/alerta/download/Alerta.apk` и новый номер сборки.
